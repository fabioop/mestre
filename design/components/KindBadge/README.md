# KindBadge

The item's kind as one word (`ItemKind.label`) at the trailing edge of every row, in `kind` (12 pt) on `ink-secondary`.

- It is the launcher's answer to extension icons: a word, so a list of mixed results scans by column. It never changes on selection.
- Don't: colour badges per kind, use icons here, hide it on the selected row, add a count.
