# Welcome

The first-run window, 460 pt wide, padding 28, a 20 pt stack: the app icon at 96, "Welcome to Mestre" in `window-title`, the hotkey in `hotkey-display` inside an `ink-quaternary` chip at `radius-tile`, a grid of four typed examples in `field-mono`, the permissions note in `callout`, a launch-at-login switch, and a footer with Settings…, the config path and a default "Get Started" button.

- It is the only place with a sentence of marketing ("A launcher that lives in your menu bar."). Shown once (`onboarding.showWelcome`), reachable again from the menu.
- Don't: a carousel, a progress indicator, a sign-in.
