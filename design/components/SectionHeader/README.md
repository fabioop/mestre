# SectionHeader

An uppercase label in `section` (11 semibold, 0.5 tracking, `ink-secondary`), bottom-aligned in a 24 pt row, inset 10. One of the two typographic signatures. Used for Recent · Features · Commands on the home screen, for "Actions" above the actions menu, and when a provider groups its results.

- Never for a single section, never between results of one provider. Moving the selection onto the first row of a section scrolls the header into view.
- Don't: a divider under it, a count after it, a disclosure control.
