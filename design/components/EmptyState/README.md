# EmptyState

A single 44 pt line in `ink-secondary` below the hairline when the query yields nothing or a provider wants to teach its grammar.

- Texts name the query or the grammar: "No apps match “xqz”", "Indexing apps…", "Keep awake: 45m, 2h, until 18:30, off". Never "No results".
- Don't: an illustration, a button, a second line.
