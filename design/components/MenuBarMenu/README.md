# MenuBarMenu

The status item's NSMenu: Open Mestre (with the hotkey), Rebuild App Index, —, Settings…, Edit Config File, Welcome Guide, —, Quit Mestre. Seven items, system-drawn, never more.

- The item icon is `sparkle.magnifyingglass` as a template image, `cup.and.saucer.fill` while keep-awake runs; tooltip "Mestre" or "Mestre: awake …".
- Features never get menu items. Don't: a status line, a submenu, a custom view.
